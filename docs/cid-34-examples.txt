CID-34 — Bottom-panel row layout
================================

Each row in the bottom browsing panel renders as a single line:

    [cursor/play mark] [type tag] [title]    [artist · album]

The `artist · album` segment drops the album when:
  - the row's Album field is empty, or
  - the row IS the container being browsed (Library albums / artists,
    Playlists tab, album-tracks drill-down): the detail header already
    names the container, so repeating it would be noise.

The artist column falls back to just the album when artist is missing,
and renders empty when both are missing — we never invent metadata.

Compact-spacing notes
----------------------

  - The two-cell gap (`"  "`) between the title and the subtitle
    columns is unchanged from before this card.
  - Single trailing " · " only appears when both artist and album
    are non-empty; a missing artist or missing album drops the
    separator cleanly.
  - The subtitle column uses ansi.Truncate with a "…" ellipsis when
    the combined metadata exceeds the available width.
  - Row height is unchanged: every row is exactly one terminal line.
  - Selection (▸/▸/▸ cursor markers) and current-track (▸ playing
    marker) indicators are preserved across all widths.
